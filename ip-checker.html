How this IP address checker works

When you open this page, our server reads the public IP address your connection uses to reach socialtush.com and checks it against live IP intelligence sources. Lookups run on our server, so no API keys are exposed in your browser:

  • proxycheck.io: identifies VPN servers, open proxies, Tor and the connection type (residential, wireless, business or hosting), plus the ISP and location.
  • The Tor Project's exit node list: the official, regularly updated list of Tor exit relays.
  • ipapi.is: an independent source for ISP and location details, used when the main source is unavailable.

If a detection source does not respond, the tool shows Detection inconclusive rather than claiming the address is VPN-free.

What is a public IP address?

Every device on the internet is reached through an IP address. Your public IP address is the one websites see. It is assigned by your internet provider and is usually shared by every device on your home or office network.

Addresses such as 192.168.1.10, 10.0.0.5 or 172.16.0.2 are private: they only work inside your local network, so they cannot be looked up online. There are two versions: IPv4 addresses look like 105.163.0.1, and the newer IPv6 addresses look like 2001:4860:4860::8888.

How VPN detection works

A VPN sends your traffic through a server operated by the VPN provider, so websites see the VPN server's IP address instead of yours. Detection services recognise those servers in several ways:

Known VPN provider servers

Commercial VPN companies run large, well-known server fleets. Detection providers track these addresses and can often name the operator.

Hosting and data-centre networks

Most VPN and proxy servers live in data centres rather than homes. Knowing whether an address belongs to a residential, mobile, business or hosting network helps separate ordinary visitors from relayed traffic.

Why detection is never 100% certain

New VPN servers appear every day, and some services route traffic through ordinary home connections. That is why we show which source reported what, and mark results as inconclusive when sources disagree.

Proxy detection

A proxy forwards requests on someone else's behalf. Open HTTP and SOCKS proxies are often abused for spam and fraud. This tool flags addresses that detection sources have seen operating as proxies, and shows the proxy type when it is known.

Tor detection

Tor relays traffic through several volunteer servers to hide its origin. The last server, the exit node, is the address websites see. We check every IPv4 address against the Tor Project's official exit node list, refreshed every hour.

Your privacy

We do not save the IP addresses you check or your own IP address in any database. To answer a lookup, the address is sent to proxycheck.io and ipapi.is, and the result is kept in temporary memory for up to 15 minutes. Lookups are rate limited to prevent abuse.

Frequently asked questions

Is my IP address using a VPN?

Open this page and the tool checks your public IP automatically. A green result means no VPN, proxy or Tor was detected; red means one was detected; yellow means the result is inconclusive, for example when detection services are unavailable or disagree.

How do I check if an IP address is a VPN?

Paste any public IPv4 or IPv6 address into the IP checker and press Check IP Address. The address is checked against proxycheck.io VPN and proxy data and the Tor Project exit node list, and the actual results are shown.

Why does the location show a different city from where I am?

IP location is approximate. It usually shows where your internet provider registers or routes the address, which can be a nearby city or the provider's regional hub.

What is the difference between a public and a private IP address?

A public IP address identifies your connection on the internet. Private addresses such as 192.168.x.x or 10.x.x.x are only used inside your home or office network and cannot be looked up online.

Is this IP checker free?

Yes. The SocialTush IP address checker is free to use without signing up.

Do you store the IP addresses I check?

No. Lookups are not saved to a database. Results are kept in temporary memory for up to 15 minutes to avoid repeated lookups, then discarded.
