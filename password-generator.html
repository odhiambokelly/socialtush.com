      What makes a password strong?

      A strong password is long, random and unique. Attackers don't guess one password at a time: they run billions of guesses per second, starting with dictionary words, names, dates and common patterns like Password123!. A truly random string avoids every one of those shortcuts.

      Why longer passwords are safer

      Every character you add multiplies the number of possible passwords. A random 8-character password with all character types has about 52 bits of entropy and could be cracked in hours or days by a large cracking rig. At 16 characters it reaches about 105 bits, which would take longer than the age of the universe. That's why our strength meter rewards length, not just variety.

      Why random passwords are recommended

      People are predictable: we capitalise the first letter, add a number at the end and replace "a" with "@". Cracking tools know these habits. This generator uses your browser's cryptographically secure random number generator (the Web Crypto API), so every character is chosen independently and unpredictably.

      How to use uppercase, lowercase, numbers and symbols

      Using all four character types gives a pool of up to 94 characters, so each character adds about 6.5 bits of entropy instead of 4.7 bits for lowercase only. If a website rejects certain symbols, turn on Exclude ambiguous symbols, or use a custom character set with only the characters it allows. To read a password aloud or type it on a TV or phone, turn on Exclude similar characters so O and 0, or l and 1, can't be confused.

      Why you should never reuse passwords

      When a website is breached, attackers try the leaked email and password on email, banking and social media accounts ("credential stuffing"). One unique password per account stops a single leak from spreading. A password manager makes this easy: generate a new password here, copy it, and save it in your manager.

      How SocialTush protects your passwords

      • Passwords are generated on your device by crypto.getRandomValues(). Math.random() is never used.
      • They are never sent to SocialTush or any third party, never saved in a database, never logged and never put in the page address.
      • Recent passwords are kept in this tab's memory only, so you don't lose one before copying it. They are wiped when you close or leave the page.

      Frequently asked questions

      Is this password generator safe to use?

      Yes. Passwords are created inside your browser with the Web Crypto API (crypto.getRandomValues). They are never sent to SocialTush or anyone else, never stored, and are cleared when you leave the page.

      How long should my password be?

      Use at least 16 characters for important accounts. Every extra character multiplies the number of possible passwords, so length adds more security than anything else.

      Should I include symbols and numbers?

      Yes, when the website allows them. Mixing lowercase, uppercase, numbers and symbols enlarges the set of possible characters, which makes a random password much harder to guess.

      What is password entropy?

      Entropy, measured in bits, describes how many guesses an attacker would need. Each bit doubles the work: 60 bits is strong for most accounts and 100 bits or more is very strong.

      Can I generate a 16-character password with symbols?

      Yes. 16 characters with all character types is the default. You can also choose any length from 4 to 128 and generate up to 10 passwords at once.

      Why should I not reuse passwords?

      If one website is breached, attackers try the same email and password on other sites. A unique password for every account stops one leak from exposing the rest.
